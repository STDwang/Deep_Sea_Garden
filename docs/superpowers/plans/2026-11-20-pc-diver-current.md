# PC 潜水员与水流 · 2026-11-20

用户明确新增：程序化潜水员、玩家控制、优化藻类同步摆动；随后确认标准 WASD（W 前、A 左、S 后、D 右），鼠标控制方向。此前纯美术阶段范围由本次指令扩展为可控制的观景角色，仍不增加任务、计分、收集或解锁。

实现：沿用 Cold Smoke 双后端与 SDF 表面网格，参考 08_skier.js、08g_human.js 的程序化身体与关节驱动方法。没有复制庞大的滑雪运动解算或动作捕捉模块。潜水员独立生成 SDF 躯干、肢体、面镜、气瓶、呼吸管、背带、脚蹼，使用关节编号在顶点着色器中执行髋膝与手臂形变。

鼠标控制采用画面点击激活、鼠标位移转向和左右边缘持续转向，不调用指针锁定。Esc、窗口失焦或切后台清空输入；再次点击恢复。W 沿俯仰方向游动，A/D 横移。平滑速度、转向和第三人称镜头；地面、主要岩体、边界提供基础约束，尚不对任意网格作精确碰撞。

海流为多尺度解析近似场，CPU 与 GPU 使用同一公式。大尺度流向随时间和空间变化，深度调制流速；藻株种子调制柔度，高处产生时间延迟，茎叶共享位移函数；局部叶片颤动使用不同相位。根部位移为零，避免整体海藻平移。该方案不是 Navier–Stokes 求解器。

验证：见 minitool/test/check.mjs 与 minitool/review/pc-diver.md。当前只支持本地 PC 操作验证，未扩展手机输入。
