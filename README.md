# 深海花园

**一个可以直接在浏览器里畅游的梦幻海底世界。**

高耸的海藻森林、透过荡漾水面洒下的光柱、一艘沉船、从头顶缓缓游过的蝠鲼。
而这一切全部由代码生成：没有图片、没有 3D 模型、没有声音文件。整个世界装在**一个约 96 KB 的 HTML 文件**里。

## 试玩

1. 下载 [`index.html`](index.html)。
2. 在台式电脑上用 **Chrome** 或 **Edge** 打开它。
3. 稍等几秒让世界构建完成，然后点击 **潜入** 开始畅游。

无需安装任何东西，离线也能玩。它需要支持 **WebGPU** 的浏览器。如果你看到 *"此场景需要 WebGPU"* 的提示，请更新浏览器或换用 Chrome / Edge。

## 海底有什么

- **海藻森林** 随水流摇曳，闪烁着细小的金色和绿色光斑
- **光柱** 从波动的水面倾泻而下，海床上闪烁着游动的焦散光纹
- **一艘沉没的木船**、**巨大的石制鲸尾**、岩石拱门、峡谷和漂浮的巨石
- **蝠鲼**、鱼群、上升的气泡和漂浮的微粒
- **紫色洞窟**，长着发光的洋红色地表植物、珊瑚和桶状海绵
- **即听即生成的音景**：低沉的轰鸣、远处的鲸鸣、轻柔的风铃与气泡声

## 操作

| | 键盘 & 鼠标 |
|---|---|
| 环顾四周 | 移动鼠标 |
| 游动 | `W` `A` `S` `D` |
| 上浮 / 下潜 | `E` / `Q` |
| 加速游动 | 按住 `Shift` |
| 跳转到观景点 | `1` 到 `6`（对应各处取景位置） |
| 菜单 | `Esc` 释放鼠标并打开操作列表菜单；**继续** 返回场景 |
| 声音开 / 关 | `M`（潜入后声音才会开始） |
| 性能统计 | `H` |
| 画质档位 | 菜单中的 **低**、**中** 或 **高**（会重新加载页面） |

海床、岩壁和拱门是实体：你会沿着岩石滑行而不是穿进岩石，同时所有隧道和拱门都能正常通过。海藻、植物、珊瑚、海绵、散落的石块、漂浮巨石、沉船和鲸尾都可以穿行。

**触屏设备：** 按住一根手指向前游动，滑动来转向。按下第二根手指加速。角落里的 `≡` 按钮打开菜单。手机上场景始终以横屏显示，并从低档或中档画质开始。（触屏支持为实验性功能。）

## 画质档位

菜单中的 **低**、**中** 和 **高** 按钮用于选择画质档位，当前档位会高亮显示。每个档位都是同一个世界，只是内容更精简：

| 档位 | 说明 | 首次访问时的适用对象 |
|---|---|---|
| **高** | 完整场景 | 台式电脑 |
| **中** | 一半的海藻叶片、光斑和卵石；小岩石、海绵和珊瑚不投射阴影 | 8 GB 内存的手机 |
| **低** | 四分之一的海藻叶片、关闭抗锯齿、更粗糙的岩石和珊瑚、简化光照、以 480p 起步 | 其他手机，以及 4 GB 或以下内存的电脑 |

如果加载时页签崩溃，或显卡驱动放弃渲染，页面会自动以低一档重新开始。浏览器会记住你上次选择的档位，以及场景最终适配的分辨率和绘制距离，供下次访问使用。

## 工作原理

- 海床在每次打开页面时由显卡实时雕刻生成，然后装饰上约两百万株海藻叶片和植物、数以万计的岩石，以及成千上万的海绵、珊瑚和鱼类。
- 一切都通过 **WebGPU** 直接绘制，没有使用任何游戏引擎或 3D 库。
- 沉船、鲸尾、蝠鲼、鱼类和珊瑚都由简单的数学形体构成。
- 音效使用 Web Audio API 实时合成。
- 它以流畅运行为目标：在中高端独立显卡上以 2560×1440 约 180 fps 运行。在较慢的硬件上则以 60 fps 为目标，先小幅降低分辨率、再缩短植物和岩石的绘制距离。场景在开始菜单背后就已经以模糊状态运行，所以大部分性能调优在你潜入之前就完成了。入门级手机在低档下以 670×372 约 20 fps 运行。

## 自定义修改

可读的源代码位于 [`source`](source) 文件夹。要修改并重新构建 `index.html`，需要 [Node.js](https://nodejs.org) 18 或更新版本：

```bash
cd source
npm install
npm run build
```

构建结果会写在本 README 旁边，即新的 `index.html`。`npm run build:readable` 则生成一个未压缩版本，更方便在浏览器开发者工具中调试。

`npm run build:dev` 会生成一个单独的 `dev.html`，包含两个不属于 `index.html` 的额外工具：`F` 沿一条一分钟路径飞过整个世界，`B` 将该飞行动画作为基准测试运行并报告帧耗时和 GPU 耗时。

| 文件 | 内容 |
|---|---|
| [`source/src/world.js`](source/src/world.js) | 世界布局：岩壁、拱门、隧道、海藻森林、海绵花园、鱼群、蝠鲼、沉船和鲸尾。**建议从这里开始。** |
| [`source/src/shaders.js`](source/src/shaders.js) | 视觉外观：水体和雾的颜色、光照、海藻、岩石、水面和光柱（WGSL 着色器代码） |
| [`source/src/main.js`](source/src/main.js) | 渲染器、相机、操作控制、六个观景点，以及世界布局所围绕的相机路径 |
| [`source/src/audio.js`](source/src/audio.js) | 音景 |
| [`source/src/quality.js`](source/src/quality.js) | 画质档位：设备从哪个档位起步，以及访问之间会记住什么 |
| [`source/src/math.js`](source/src/math.js) | 噪声、随机数和网格构建辅助函数 |
| [`source/src/dev.js`](source/src/dev.js) | 开发工具（飞行预览和基准测试），仅存在于 `dev.html` |
| [`source/template.html`](source/template.html) | 场景周围的页面：加载进度条、开始菜单、链接及其样式 |

一些简单的入门修改：

- **水色：** `shaders.js` 中共享场景代码顶部附近的 `WCOL`（蓝绿色水体）和 `PCOL`（紫色洞窟）
- **阳光颜色：** 紧挨着它们的 `SUNC`
- **亮度和光柱：** `main.js` 中的 `EXPO` 和 `RAYS`
- **游动速度：** 在 `main.js` 中搜索 `26 : 7`（快速 : 正常速度）
