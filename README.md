# 深海潜水员

**一个可以直接在浏览器里畅游的梦幻海底世界。**

高耸的海藻森林、透过荡漾水面洒下的光柱、一艘沉船、从头顶缓缓游过的蝠鲼。
而这一切全部由代码生成：没有图片、没有 3D 模型、没有声音文件。整个世界装在一个独立的 HTML 文件里。

## 试玩

1. 下载 [`index.html`](index.html)。
2. 在台式电脑上用 **Chrome** 或 **Edge** 打开它。
3. 稍等几秒让世界构建完成，然后点击 **潜入** 开始畅游。

无需安装任何东西，离线也能玩。它需要支持 **WebGPU** 的浏览器。如果你看到 *"此场景需要 WebGPU"* 的提示，请更新浏览器或换用 Chrome / Edge。

## 海底有什么

- **海藻森林** 随水流摇曳，闪烁着细小的金色和绿色光斑
- **光柱** 从波动的水面倾泻而下，海床上闪烁着游动的焦散光纹
- **一艘沉没的木船**、**巨大的石制鲸尾**、岩石拱门、峡谷和漂浮的巨石
- **蝠鲼**、鱼群、上升的气泡和漂浮的微粒
- **海龟与近岸鱼群**。峡谷入口、沉船和海藻林有海龟巡游。银蓝、金橙和青绿三类鱼群各有不同的体态；游近时，身边的鱼会散开。
- **紫色洞窟**，长着发光的洋红色地表植物、珊瑚和桶状海绵
- **洞口的水母**会缓缓漂游，伞缘在暗水中发光。
- **即听即生成的音景**：低沉的轰鸣、远处的鲸鸣、轻柔的风铃与气泡声
- **海底日志**会在你到达观景位置时自动记录。菜单中可以查阅六处地点与游览线索，记录保存在当前浏览器或小红书小工具内。

## 外海测绘

在水下按 F 或点「声呐」，读出相对于视线的方向、距离和深度提示。游到潮门测站 12 米以内再次扫描，再去双环测站采第二份样本。最后返回石鲸尾扫描，回声海图会记入日志。菜单可查看进度，兼容原有六条地点记录。

原场景以密度场雕刻峡谷、拱门和洞室，再沿地表布置海藻、珊瑚与动物。原有探索依靠六个固定机位触发记录，地点之间缺少持续目标。这次在东部划出航道并加入单拱和双拱两种地标，可游半径从 150 米扩大到 174 米，平面范围约扩大 35%。沿用原有体素精度，同步扩大碰撞缓存和海床采样范围。

目前已有一条可完成、可保存的测绘任务。长期可玩性仍受固定路线限制，后续值得通过试玩观察玩家能否独立找到第一站、在哪里失去方向，以及完成后是否愿意再潜一次。小红书版本要求宿主 WebView 支持 WebGPU，发布前需在目标设备检查启动耗时、稳定性和日志恢复。

## 操作

| | 键盘 & 鼠标 |
|---|---|
| 环顾四周 | 按住鼠标左键或右键拖动，滚轮调整跟随距离 |
| 游动 | `W` `A` `S` `D` |
| 上浮 / 下潜 | `E` 或空格 / `Q`、`C`、`X` 或 Ctrl |
| 加速游动 | 按住 `Shift`，近水面时加速上浮可跃出水面 |
| 切换视角 | `V` 循环切换跟随、第一人称和远景视角 |
| 跳转到观景点 | `1` 到 `8`（对应各处取景位置） |
| 菜单 | `Esc` 打开操作列表菜单；**继续** 返回场景 |
| 自动漫游 | `R` 切换自动游动，后退取消 |
| 声呐 / 潜水灯 | 短按右键或 `F` 发出声呐，`L` 切换灯光 |
| 摄影 | `P` 进入，滚轮变焦，`Enter` 或 `P` 拍照，`Esc` 返回 |
| 声音开 / 关 | `M`（潜入后声音才会开始） |
| 性能统计 | `H` |
| 画质档位 | 菜单中的 **低**、**中** 或 **高**（会重新加载页面） |

海床、岩壁和拱门是实体：你会沿着岩石滑行而不是穿进岩石，同时所有隧道和拱门都能正常通过。海藻、植物、珊瑚、海绵、散落的石块、漂浮巨石、沉船和鲸尾都可以穿行。

**触屏设备：** 按住一根手指向前游动，滑动来转向。按下第二根手指加速。角落里的 `≡` 按钮打开菜单。手机上场景始终以横屏显示，并从低档或中档画质开始。（触屏支持为实验性功能。）

## 画质档位

菜单中的 **低**、**中** 和 **高** 按钮用于选择画质档位，当前档位会高亮显示。每个档位都是同一个世界，只是内容更精简：

| 档位 | 说明 | 首次访问时的适用对象 |
|---|---|---|
| **高** | 完整场景 | 台式电脑 |
| **中** | 一半的海藻叶片、光斑和卵石；小岩石、海绵和珊瑚不投射阴影 | 8 GB 内存的手机 |
| **低** | 四分之一的海藻叶片、关闭抗锯齿、更粗糙的岩石和珊瑚、简化光照、以 480p 起步 | 其他手机，以及 4 GB 或以下内存的电脑 |

如果加载时页签崩溃，或显卡驱动放弃渲染，页面会自动以低一档重新开始。浏览器会记住你上次选择的档位，以及场景最终适配的分辨率和绘制距离，供下次访问使用。

## 工作原理

- 海床在每次打开页面时由显卡实时雕刻生成，然后装饰上约两百万株海藻叶片和植物、数以万计的岩石，以及成千上万的海绵、珊瑚和鱼类。
- 一切都通过 **WebGPU** 直接绘制，没有使用任何游戏引擎或 3D 库。
- 沉船、鲸尾、蝠鲼、鱼类和珊瑚都由简单的数学形体构成。
- 音效使用 Web Audio API 实时合成。
- 它以流畅运行为目标：在中高端独立显卡上以 2560×1440 约 180 fps 运行。在较慢的硬件上则以 60 fps 为目标，先小幅降低分辨率、再缩短植物和岩石的绘制距离。场景在开始菜单背后就已经以模糊状态运行，所以大部分性能调优在你潜入之前就完成了。入门级手机在低档下以 670×372 约 20 fps 运行。

## 自定义修改

可读的源代码位于 [`source`](source) 文件夹。要修改并重新构建 `index.html`，需要 [Node.js](https://nodejs.org) 18 或更新版本：

```bash
cd source
npm install
npm run build
```

构建结果会写在本 README 旁边，即新的 `index.html`。`npm run build:readable` 则生成一个未压缩版本，更方便在浏览器开发者工具中调试。

`npm run build:dev` 会生成一个单独的 `dev.html`，包含两个不属于 `index.html` 的额外工具：`F` 沿一条一分钟路径飞过整个世界，`B` 将该飞行动画作为基准测试运行并报告帧耗时和 GPU 耗时。
在 `dev.html` 后加 `?spot=1` 到 `?spot=8` 可选定初始观景点，用于复查场景与镜头。

| 文件 | 内容 |
|---|---|
| [`source/src/world.js`](source/src/world.js) | 世界布局：岩壁、拱门、隧道、海藻森林、海绵花园、鱼群、蝠鲼、沉船和鲸尾。**建议从这里开始。** |
| [`source/src/shaders.js`](source/src/shaders.js) | 视觉外观：水体和雾的颜色、光照、海藻、岩石、水面和光柱（WGSL 着色器代码） |
| [`source/src/main.js`](source/src/main.js) | 渲染器、相机、操作控制、八个观景点，以及世界布局所围绕的相机路径 |
| [`source/src/diver.js`](source/src/diver.js) | 第三人称潜水员：游动逻辑移植自 Deep-Sea-Exploration，程序化低模身体、踢腿动画与跟随相机 |
| [`source/src/audio.js`](source/src/audio.js) | 音景 |
| [`source/src/quality.js`](source/src/quality.js) | 画质档位：设备从哪个档位起步，以及访问之间会记住什么 |
| [`source/src/math.js`](source/src/math.js) | 噪声、随机数和网格构建辅助函数 |
| [`source/src/dev.js`](source/src/dev.js) | 开发工具（飞行预览和基准测试），仅存在于 `dev.html` |
| [`source/template.html`](source/template.html) | 场景周围的页面：加载进度条、开始菜单、链接及其样式 |

一些简单的入门修改：

- **水色：** `shaders.js` 中共享场景代码顶部附近的 `WCOL`（蓝绿色水体）和 `PCOL`（紫色洞窟）
- **阳光颜色：** 紧挨着它们的 `SUNC`
- **亮度和光柱：** `main.js` 中的 `EXPO` 和 `RAYS`
- **游动速度：** 在 `main.js` 中搜索 `26 : 7`（快速 : 正常速度）

## 小红书小工具

在仓库根目录运行 `npm --prefix source run build:xhs`，再用 Chrome 或 Edge 打开 `xhs-preview.html` 预览小红书界面。独立预览使用同一套界面与玩法，依赖容器的功能以在小红书内的实际表现为准。

制作上传包时，将 `.tmp/xhs-garden` 里的 `index.html`、`app.js` 和 `style.css` 放在 ZIP 根目录。

小工具沿用原版 WebGPU 海底场景。端内通过容器 Storage 记录累计潜水时间。关注、分享、笔记和评论依赖当前容器提供的接口。排行榜测试需要在创服平台勾选用户头像昵称授权，AI 潜水报告需要对应小工具获得平台权限。上传后请在创服平台模拟器、Android 和 iOS 真机验证。

## 开发优先级

1. **首轮探索**。用六处已有景观建立「到达、记录、寻找下一处」的循环，游客能自由游动，也能从菜单选择观景点。到达提示参考本地 Deep-Sea-Exploration 的地标标题，固定机位参考 [web-ocean](https://github.com/noniv/web-ocean) 的 URL 参数做法。
2. **端内体验**。先验证创服模拟器与 Android、iOS 的启动、触控、存档和低画质表现。若 WebGPU 启动覆盖不足，优先验证 WebGL2 渲染方案。首轮体验观察首次打开到第一条记录所需时间、第二次发现率，以及旋转屏幕后是否容易迷路。
3. **可分享内容**。渲染和触控通过验证后，先做可保存的单张潜水照片和已发现地点文案，再增加蝠鲼巡游或轻量环境事件。用实测验证玩家是否愿意主动保存或发笔记。

### 海底生物迭代

1. **安排能看见的巡游**。先在首次潜入和常用观景点安排海龟，观察入水后几秒能否认出盾片背甲、前鳍划水和滑翔。造型与动作参考用户提供的水族馆研究。 [STILLWATER](https://github.com/cjhgit/aquarium-threejs)
2. **给各海域不同的动物活动**。参考本地 `Deep-Sea-Exploration` 的区域布群，在峡谷、沉船、洞窟放置近景鱼群，再为沉船与洞口补珊瑚前景。鱼继续使用 GPU 实例化，群游参考 Pelagic 的个体差异和队形变化，近距离用潜水员位置驱动避让，低画质保留近景鱼群并降低大群密度。 [Pelagic](https://github.com/ZhaoChaoqun/fish-school)
3. **验证触控与构图**。在小红书版添加深度显示、长按上浮和下潜，按观景点对照动作与景物可见度。继续用固定机位复现渲染问题，再在端内确认帧率与触控。 [web-ocean](https://github.com/noniv/web-ocean)
4. **打磨抬头看水面的光线与潜水员**。复用波面贴图的多级采样，按斜率方差展宽太阳亮斑，并让光束与海床焦散共用细波纹来源。参考本地 `Deep-Sea-Exploration` 改进横向泳姿、单瓶背具、双片面镜和调节器，给触屏补第一和第三人称切换。
