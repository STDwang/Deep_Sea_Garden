# 深海花园：美术场景

当前目标：迭代美术、光效、场景和镜头观感，以 Cold Smoke 的成品画质作为视觉对照。按用户最新指令增加代码建模的潜水员与 PC 自由游动；没有任务、计分或解锁。拍照与相册界面不对外展示。

## 运行

在工程根目录执行：

```powershell
node minitool/build.mjs
node minitool/serve.mjs
```

打开 http://localhost:61307/ 。默认 WebGPU，不可用时使用 WebGL2；`?backend=webgl2` 强制第二条路径。点击画面开始控制：W 前进、S 后退、A 左移、D 右移，鼠标移动改变朝向与俯仰，W 沿视线方向游动；Esc 退出控制，重新点击恢复。鼠标在左右边缘可持续转向，移出画面停止转向。底部切换三个出发点，右上可调画质和声音。默认静音，不强制横屏或锁定指针。

潜水员由 SDF 躯干、曲面肢体和装备代码生成，包含面镜、呼吸管、气瓶、背带、手套和脚蹼。髋膝分级驱动踢腿，运动有加减速和轻微水流漂移。第三人称镜头平滑跟随；地面与主要岩体提供基础约束，尚非任意网格精确碰撞。

海流为 CPU / GPU 共用的解析近似，随位置、深度、时间变化；每株植物按柔度与高度产生延迟，茎叶共享形变，叶片增加局部颤动。它不是完整流体求解器。

构建仅使用原工程 `source/node_modules/esbuild`，不新增 npm 依赖。构建产物在 `minitool/dist/`；原有桌面版 `index.html`、`source/` 保持原样。

## 验证边界

`node minitool/test/check.mjs` 检查几何、法线、索引、实例记录和两种着色器源码生成。WebGPU / WebGL2 的真实编译与画面另在浏览器检查。不能把桌面浏览器验证写成小红书真机验收。

本轮交付美术场景及 PC 潜水员控制，不声称画质已经主观达到参考成品。后续应以固定机位截图与动态镜头逐项对照：植物造型、岩石材质、明暗层次、空间尺度、阴影、光束稳定性与生物质感。

小红书创服模拟器、Android 真机和 iOS 真机的同包验证仍未执行，需在平台当前开发口令与规范下完成后再上传发布。
