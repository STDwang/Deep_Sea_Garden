# 地形地貌丰富化验收（2026-11-20 第二轮）

## 依据

- 用户附《雪迹》制作口播稿，核心方法论 =「存方法不存结果」：噪声造地形、规则散布、逐像素着色、程序化音频。
- ABZU 美术研究：分区主导色、大形状剪影引导视线、前中远景分层、夸张光柱、梦幻景深、鲸骨/海沟的远古海洋感。

目标：**只做地形地貌与观感，不加玩法**；落在 minitool 开发线，保持双后端 SSL 兼容与每帧零分配。

## 改动清单

### 1. 高度场（10_world.js `height()`）
从近乎平面（±1.5m）重建为程序化地貌：

| 手法 | 实现 |
|---|---|
| 域扭曲 | wx/wz 各叠一层 fbm2 偏移 ±3m |
| 大势起伏 | fbm2(wx*.06,wz*.06,4)×2.0 |
| ridged 礁脊 | `1-abs(fbm2(wx*.11,wz*.11,4))` 三次方 ×3.0 |
| 蜿蜒海沟 | 沿 x=-13+sin(z*.07)*3.5 的高斯下切 3.4m |
| 抬升礁台 | shelf 掩膜 ×2.2m（紫湾区） |
| 沙纹 | 定向正弦 ×0.13 |
| 中央通道 | 按 \|x\| 把起伏压到 30%，保证巡航平顺 |
| 软钳制 | tanh 限制在 -6.3±3.8，防止潜水员撞地 |

实测值域 **-8.75 ~ -2.75（约 6m 起伏）**，原为 ±1.5m。`height()` 被地面/海藻/珊瑚/鲸尾/相机贴地全局复用，改一处全场景联动。

### 2. 地面顶点色分层（10_world.js）
网格 110→146，顶点色按坡度(slope)、深度(deep)、暖区/紫区混合沙—岩—泥。地面三角形 2.4万→15.8万，全场 124.7万三角形 / 22.18MiB mesh。

### 3. 新增 ABZU 标志性地貌（静态几何，零帧开销）
- **鲸骨遗迹** `whaleBones()`：脊椎 + 12 根半埋肋骨拱，位于 (26,-57) 深海台地。
- **热液喷口** `vent()`：锥形烟囱 + 向上扩散烟柱，×3 位于海沟 (-15,-13)/(-12,-26)/(-17,-38)。
- **岩柱石林** ×8 散布于西侧深海。
- 岩拱中心 cy 由硬编码 -5.3/-5.8 改为跟随局部 height()，新地形下保持贴地。
- 全部登记 obstacles，潜水员避障生效。

### 4. 着色器（20_render.js）
- `OCEAN_FRAG` kind=0 地面：坡度三平面岩石采样 + 深海泥色带（首版拉丝过强，已将采样 scale 0.9→0.32、强度降低）。
- `BACKGROUND_FRAG`：3 层 fbm2 远景海山剪影 + 近深远浅大气透视；bgP 管线补 SL.hash + SL.noise。

## 验证结果

- 构建与自动检查 PASS：双后端着色器源码均生成，碰撞/巡航/空间流测试通过。
- **真实 Chrome WebGPU 与强制 WebGL2 均编译通过、运行时零错误**（控制台 errors=0）。
- 高度场关键坐标值用独立脚本核算：喷口在 -7.x 海沟、鲸骨在 -3.25 台地、拱门贴地，符合设计。

## 已知不足 / 下一步

1. 鲸骨偏细小，远距离辨识度低；可放大 1.4× 或补一具侧卧的完整骨架。
2. 喷口烟柱与周围岩壁色调接近，对比不足；可让烟柱更暖/更暗或加微粒上升。
3. 整体色调仍偏青绿灰，雾较重，ABZU 的深蓝→金黄→幽紫三段分层与「绘画感」尚不充分——需下一轮专门做色彩分级与降雾。
4. 高空俯瞰机位易被中央巨石群遮挡，属布局问题，如需全景验收应调整巨石分布或提高机位。
5. 本轮仅桌面浏览器验证，小红书模拟器 / Android / iOS 真机未验收。
